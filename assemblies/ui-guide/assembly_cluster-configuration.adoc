= Cluster configuration

:context: cluster-configuration

[role="_abstract"]
As a cluster administrator, you must complete administrative tasks in the Red{nbsp}Hat {ocp-name} cluster to enable access to agent configurations in {ProductFullName}.

You must complete the following administrative tasks:

* The large language model (LLM) deployment
* A secret for the LLM API key in the {ProductShortName} namespace
* An LLM gateway
* The Tackle custom resource configuration for agents
