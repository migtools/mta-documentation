= About the Agent AI
:context: agent-ai

[role=_abstract]
To understand client-side autonomous execution, review how the Agent AI operates within your environment. The Agent AI performs local code modifications directly in your workspace.

The Agent AI operates within the developer integrated development environment (IDE). It executes targeted fixes on specific files without requiring a full hub re-analysis cycle.

When diagnostic or migration issues are discovered in a file, the Agent AI generates local resolution suggestions. It presents proposed changes directly within the workspace for user review before applying them.
