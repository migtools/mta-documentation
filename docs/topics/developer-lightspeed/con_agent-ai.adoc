= About the Agent AI
:context: agent-ai

[role="_abstract"]
The {mta-dl-plugin} extension works with any Agent Client Protocol (ACP)-compliant agent binary or directly with a large language model (LLM). The agent uses Model Context Protocol (MCP) tools to run an automated analysis across multiple files.

You can configure any ACP-compliant agent binary in the extension settings. Agents rely on relevant project context by reading the project files, searching for issue patterns, resolving dependencies, and analyzing the project structure before suggesting a code resolution. 

The code resolutions suggested by the agent is not written directly to the disk. When you run the agent AI, review the modified files with a diff preview in the chat log and accept or reject the changes. The agent continues to work with the files with accepted changes. The diff preview of the code changes is available for an in-line or a batch review. Perform inline review as the changes are made in the source code or batch review after the changes are written in multiple files. 

To support simple code fixes requirements and environments where you cannot run autonomous agents, you can also disable the agent mode in the extension settings for an LLM-only workflow. In this workflow, {mta-dl-plugin} generates a diff version per file with suggested changes that you can accept or reject but {mta-dl-plugin} does not run any follow-up analysis to resolve dependency issues or secondary issues caused by the fix.

To promote portability, the migration intelligence is stored in a package that has the skills, prompts, and agent instructions. The skills files follow the Agent Skills format that any agent can read. Agents that use the migration intelligence package in any other environment, such as a command-line interface (CLI), generate the same code changes for a specific migration issue.

To perform the analysis, the agents use Model Context Protocol (MCP) tools. Enable agents to use additional MCP tools for language-specific tasks such as Maven index search (needs internet access) and npm audit. MCP bridge for standalone analysis server.

* Agent permission control: Configure the permissions for the agent you choose in the MTA Visual Studio Code extension.
