= Private endpoint configuration
:context: ip-protection-config-pointers

[role="_abstract"]
A self-managed model requires the {mta-dl-plugin} default large language model (LLM) provider uniform resource locator (URL) to point to a private inference endpoint. The URL location depends on your deployment:

* Local integrated development environment: Configure the custom LLM endpoint URL in the `provider-settings` configuration in {mta-dl-plugin}.

* Centralized configuration management mode: The provider endpoint URL is set in the central configuration administered through the {ProductShortName} hub.

Self-managed endpoints require authentication credentials, such as API keys or bearer tokens. These credentials require secure storage and must not be committed to source control.
