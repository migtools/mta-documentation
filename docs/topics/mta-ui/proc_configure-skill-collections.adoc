= Configure skill collections

[role="_abstract"]
To simplify configuration and skill management, optionally group skills into skill collections.

.Prerequisites

* You configured at least one skill.

.Procedure

. Navigate to the *Skills* page in the *Agentic* section.
. Click *Create skill collection*.
. Click *Group existing skills* to group specific skills or *Enumerate an image* to create a skill collection per skill in the Open Container Initiative (OCI) image.
. If you selected *Group existing skills*, configure the members:
.. Enter the name of the skill.
.. Select *Skill card*, *Image*, or *Git* as the skill source.
.. Depending on the skill source, configure the repository reference (*Ref*), sub path, image URL, or a skill card.
. Click *Create*.
