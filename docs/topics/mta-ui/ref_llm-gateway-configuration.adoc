= LLM gateway configuration

[role="_abstract"]
The large language model (LLM) gateways for agents are LLM provider-model pairs that you deploy as custom resources (CRs) in your cluster.

You can edit and deploy the following sample LLM gateway configurations:

* `gateway_vertex_ai.yaml` - GCP Vertex AI with Claude
* `gateway_openai.yaml` - OpenAI GPT-4o
* `gateway_anthropic.yaml` - Anthropic direct API
* `gateway_aws_bedrock.yaml` - AWS Bedrock
* `gateway_xai.yaml` - xAI (Grok)

.Example `gateway_vertex_ai.yaml`
[source,yaml]
----
apiVersion: konveyor.io/v1alpha1
kind: Gateway
metadata:
  name: gcp-vertex-ai
spec:
  provider: gcp-vertex-ai
  endpoint: "https://global-aiplatform.googleapis.com"
  credentialRef:
    secretName: vertex-credentials
  model:
    name: claude-sonnet-4-5@20250929
    contextWindow: 200000
    tier: premium
----

.Example `gateway_xai.yaml`
[source,yaml]
----
apiVersion: konveyor.io/v1alpha1
kind: Gateway
metadata:
  name: grok
spec:
  # Provider must be "xai" forwards XAI_API_KEY.
  provider: xai
  # xAI API host. The controller's verification probe appends /v1/models;
  # goose defaults XAI_HOST to https://api.x.ai/v1.
  endpoint: "https://api.x.ai"
  credentialRef:
    secretName: grok-credentials
    key: api-key
  model:
    name: grok-4
    contextWindow: 256000
    tier: premium
----
