Converting OpenShift BuildConfigs to builds (Technology Preview)::
You can convert legacy Red Hat OpenShift BuildConfig resources (build.openshift.io/v1) into Kubernetes-native Shipwright Build custom resources (shipwright.io/v1beta1) during the mta-ops transform pipeline.This capability is a Technology Preview feature. By executing mta-ops transform with the BuildConfigToBuildsPlugin stage, the tool converts Docker and Source-to-Image (S2I) build strategies, resolves image stream references by using --imagestream-mapping and --registry-mapping, generates ServiceAccount resources, and emits whiteout files for original BuildConfig objects.
