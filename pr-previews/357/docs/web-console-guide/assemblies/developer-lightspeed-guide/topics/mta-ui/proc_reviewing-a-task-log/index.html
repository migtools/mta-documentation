Reviewing a task log

To find details and logs of a particular {ProductFullName} task, access the Task Manager page.

Procedure

  1. In the Migration view, click Task Manager.

  2. Click the Options menu ({kebab}) for the selected task.

  3. Click Task details.

    Alternatively, click the task status in the Status column.
