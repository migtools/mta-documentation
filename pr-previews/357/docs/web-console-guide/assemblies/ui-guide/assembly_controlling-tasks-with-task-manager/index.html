Managing {ProductShortName} tasks by using Task Manager

To get information about the {ProductFullName} tasks queued for execution, access Task Manager.

Task Manager handles the following types of tasks:

  • Application analysis

  • Language discovery

  • Technology discovery

Warning

Multi-user access restrictions are not enforced on resources. For example, an analyzer task created by a user can be canceled by any other user.

Displaying {ProductShortName} tasks

To display information related to {ProductFullName} user interface tasks, access Task Manager.

Procedure

  • Depending on your scenario, display information about {ProductShortName} tasks either of the following ways:

    • To display active tasks, open the Task Manager drawer by clicking the notifications button.

    • To display all tasks, open the Task Manager page in the Migration view.

Reviewing a task log

To find details and logs of a particular {ProductFullName} task, access the Task Manager page.

Procedure

  1. In the Migration view, click Task Manager.

  2. Click the Options menu ({kebab}) for the selected task.

  3. Click Task details.

    Alternatively, click the task status in the Status column.
