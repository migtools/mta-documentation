Revoke API keys as a migrator

As a migrator, you can revoke an application programming interface (API) key before its lifespan period in {ProductFirstRef} web console.

Prerequisites

  • You have installed {ProductShortName} {ProductVersion} in a Red Hat OpenShift cluster.

Procedure

  1. Log in to the {ProductShortName} web console.

  2. In the Migration mode, in the upper-right corner, click your username.

  3. Click Tokens.

  4. On the Tokens page, click the options icon.

  5. Click Revoke.
