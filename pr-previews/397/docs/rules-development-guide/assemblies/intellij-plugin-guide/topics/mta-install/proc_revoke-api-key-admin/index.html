Revoke API keys as an administrator

As an administrator, you can revoke an application programming interface (API) key before its lifespan period in the migration toolkit for application (MTA) web console.

Prerequisites

You installed {ProductShortName} {ProductVersion} in a Red Hat OpenShift cluster.

Procedure

  1. Log in to the {ProductShortName} web console.

  2. In the Administration mode, click User Management.

  3. Click Tokens.

  4. On the Tokens page, click the options icon.

  5. Click Revoke.
