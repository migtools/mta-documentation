Configuring proxy settings

To enable the {ProductFullName} to access external network resources through a secured gateway, configure HTTP and HTTPS proxy settings in the user interface. Establishing these connection parameters ensures that your modernization projects can retrieve essential metadata and updates.

Procedure

  1. In the Administration view, click Proxy.

  2. Enable the HTTP proxy or HTTPS proxy switch to enable the proxy connection.

  3. Enter the following information:

    • Proxy host

    • Proxy port

  4. Optional: Enable the HTTP proxy credentials or HTTPS proxy credentials switch to enable authentication.

  5. Click Insert.
