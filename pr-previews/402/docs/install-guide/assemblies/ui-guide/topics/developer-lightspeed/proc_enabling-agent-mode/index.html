Enable agent mode

To verify code suggestions automatically with a local build dry run, enable agent mode in the {mta-dl-plugin} through the Visual Studio Code command palette or the extension settings panel.

Prerequisites

  • You have installed the {mta-dl-plugin} extension in Visual Studio Code.

  • Your project has a supported build file (pom.xml, build.gradle, or package.json) at the repository root.

  • You have installed the corresponding build tool (Maven, Gradle, or npm) and added it to your system PATH.

Procedure

  1. Enable agent mode in one of the following ways:

    • By using the command palette:

      1. Press Ctrl+Shift+P on Linux or Windows, or Cmd+Shift+P on macOS, to open the command palette.

      2. Type Preferences: Open User Settings (JSON) to open the settings.json file.

      3. Set the mta-vscode-extension.genai.agentMode parameter to true.

    • By using the extension settings panel:

      1. Click Extensions > {mta-dl-plugin} > Settings.

      2. Select the Agent Mode checkbox to enable agent mode.

  2. Restart the integrated development environment (IDE) language server when you are prompted to apply the change.

Verification

  1. Click View > Output > Red Hat Developer Lightspeed to open the Lightspeed output panel.

  2. Request a code suggestion.

  3. Verify that the output panel displays entries similar to the following output:

    [Agent Mode] Running build dry-run: mvn compile -q
[Agent Mode] Dry-run completed: SUCCESS (exit 0)
[Agent Mode] Applying verified suggestion to workspace
