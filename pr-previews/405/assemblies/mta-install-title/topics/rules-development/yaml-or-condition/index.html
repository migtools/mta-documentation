OR condition

The or condition performs a logical OR operation on the results of an array of conditions. The condition matches when any of its child conditions match.

when:
  or:
    - <condition1>
    - <condition2>

For example:

when:
  or:
  - java.dependency:
      name: junit.junit
      upperbound: 4.12.2
      lowerbound: 4.4.0
  - java.referenced:
      location: IMPORT
      pattern: junit.junit
