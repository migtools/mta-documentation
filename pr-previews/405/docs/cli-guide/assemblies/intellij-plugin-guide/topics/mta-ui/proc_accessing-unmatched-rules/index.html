Accessing unmatched rules

To review the rules that did not find matching rules during an application analysis, access the list of unmatched rule IDs in the {ProductFullName} user interface (UI).

Note
 To access unmatched rules, you must run the analysis with enhanced logging enabled.
Procedure

  1. Navigate to Advanced under Application analysis.

  2. Select Options.

  3. Check Enhanced advanced analysis details.

  4. Run an analysis.

  5. Access unmatched rules:

    1. Navigate to Reports in the side drawer.

    2. Click View analysis details, which opens the YAML/JSON format log view.

    3. Select the issues.yaml file.

    4. For each ruleset, there is an unmatched section that lists the rule IDs that do not find matching rules.
