Assessing an application

Estimate the risks and costs involved in preparing applications for modernization by performing an application assessment in the {ProductFullName} user interface (UI).

The {ProductFullName} assesses applications according to a set of questions relevant to the application, such as dependencies. To assess the application, you can use the default Legacy Pathfinder {ProductShortName} questionnaire or import a custom questionnaire.

Important
 You can assess only one application at a time.
Note

During the assessment, you might encounter false positives in an application that cannot be fully resolved. This can happen because {ProductShortName} cannot discover the class that is being called. Therefore, {ProductShortName} cannot determine whether it is a valid match or not. You can use the following solution to resolve the issue:

  1. Ensure that the maven settings can get all the dependencies.

  2. Ensure the application can be fully compiled.
Prerequisites

  • You are logged in to an {ProductShortName} server.

Procedure

  1. In the {ProductShortName} user interface, select the Migration view.

  2. Click Application inventory in the left menu bar.

  3. Select the application you want to assess.

  4. Click the Options menu ({kebab}) at the right end of the row and select Assess from the drop-down menu.

  5. From the list of available questionnaires, click Take for the desired questionnaire.

  6. Select Stakeholders and Stakeholder groups from the lists to track who contributed to the assessment for future reference.

    Note
    		 You can also add Stakeholder Groups or Stakeholders in the Controls pane of the Migration view. For more information, see Configuring a {ProductName} instance.

  7. Click Next.

  8. Answer each Application assessment question and click Next.

  9. Click Save to review the assessment and proceed with the steps in Reviewing an application.
