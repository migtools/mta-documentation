Connecting the CLI to the {ProductShortName} hub

To use organization-standard configuration for analysis and rules, you must authenticate the command-line interface (CLI) to the {ProductFirstRef} Hub.

Prerequisites

  • You have installed {ProductShortName} 8.2.0 in a Red Hat {ocp-name} cluster.

Procedure

  1. Log in to the {ProductShortName} Hub:

    $ mta-cli config login

  2. Enter the Host to connect to the Hub:

    Host: \https://mta-namespace.apps.cluster.example.com/hub

    • The Host value is the {ProductShortName} web console URL that exposes the hub endpoint.

  3. Open the displayed OpenID Connect (OIDC) device authentication URL in your browser.

  4. Log in by using the {ProductShortName} web console credentials.

  5. Copy the user code displayed in the {ProductShortName} {CLIName}.

  6. Enter the user code in the browser to authenticate the device.
