Importing a list of applications

To add and prepare multiple applications for analysis, import an application list into the {ProductFullName} user interface (UI).

You can add several applications in bulk by using a comma-separated values (CSV) file and importing this file to the {ProductShortName} UI.

Note
 Importing a list of applications does not overwrite any of the existing applications.
Procedure

  1. Download a CSV template for importing application lists:

    1. In the Migration view, click Application Inventory.

    2. Click the Options menu ({kebab}) to the right of Review.

    3. Click Manage imports to open the Application imports page.

    4. Click the Options menu ({kebab}) to the right of Import.

    5. Click Download CSV template.

  2. Add the list of applications to the .csv import file. Ensure the file contains all the required information in the required format.

  3. In the Migration view, click Application Inventory.

  4. Click the Options menu ({kebab}).

  5. Click Import.

  6. Select the desired file and click Open.

  7. Optional: Select Enable automatic creation of missing entities. This option is selected by default.

Verification

  1. Verify that the import has completed and check the number of accepted or rejected rows.

  2. Review the imported applications by clicking the arrow to the left of the checkbox.

    Important
    		 Accepted rows might not match the number of applications in the Application inventory list because some rows are dependencies. To verify, check the Record Type column of the CSV file for applications defined as 1 and dependencies defined as 2.
