Fixed issues

Review issues that have been fixed in {ProductFullName} version 8.1.3.

You can run a new analysis after closing the review editor without accepting changes

Before this update, when you closed the resolutions in the code editor without accepting the changes, the {ProductShortName} extension remained in the resolution in progress state. As a consequence, the Continue option was disabled and you were unable to run another analysis. With this update, the {ProductShortName} extension correctly restores its state when you close the review editor without accepting the changes.
