Displaying application tags

To verify the application classification, display application tags in the {ProductFullName} user interface (UI).

Note
 You can display the tags that were attached automatically only after you ran an application analysis.
Procedure

  1. In the Migration view, click Application inventory.

  2. Click the name of the required application. A side pane opens.

  3. Click the Tags tab. The tags attached to the application are displayed.
