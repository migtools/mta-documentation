Basic authentication for local users

As an administrator, you can use a simple authentication workflow to manage users, roles, and role-based access control (RBAC) permissions in the {ProductShortName} inventory with no added infrastructure requirements.

Add users and assign roles in the web console

As an administrator, you can manage users and assign one or more roles to them for local authentication and authorization. When you assign roles to a user, they receive all the unique permissions that are associated with the roles.

Prerequisites

  • You are an {ProductShortName} administrator.

  • The cluster administrator has installed {ProductShortName} {ProductVersion}.

Procedure

  1. Log in to the {ProductShortName} web console.

  2. In the Administration mode, click User Management.

  3. Click Users.

  4. On the Create user page, enter the following information:

    • Enter the username in the Login field.

    • Enter the name of the user.

    • Enter the email address of the user.

    • Enter a new password in the Password field.

    • Enter the same password in the Confirm Password field.

    • Select one or more roles from the Roles list.

  5. Click Create.

Change password in the web console

To ensure that your account is not accessible with the default admin password, you must change your account password after you log in for the first time. When you change your password for the first time, also specify your account details.

Procedure

  1. Log in to the {ProductShortName} application with admin as your password.

  2. In the upper-right corner, click your role drop-down list.

  3. Select User account.

  4. On the Edit user page, enter the following information:

    • Enter your name.

    • Enter your email address

    • Enter a new password in the Password field.

    • Enter the same password in the Confirm Password field.

  5. Click Save.

Verification

Log out of your account and log in with your new password.

Create a custom role and assign permissions

To enforce fine-grained role-based access control (RBAC) permissions for users to perform specific tasks, create custom roles and assign specific permissions in the {ProductFullName} web console. Users can access features based on the permissions that you assign to them.

Note

You cannot alter or delete the default roles and permissions scoped to them.
Prerequisites

  • You are an {ProductShortName} Administrator user.

  • You have installed {ProductShortName} 8.2 or later.

Procedure

  1. Log in to the {ProductShortName} web console.

  2. In the Administration mode, go to User Management.

  3. Click Roles.

  4. Click the number of permissions scoped to the admin role to explore the resources and scoped permissions.

  5. On the Roles page, click Create.

  6. In the Name field, enter a unique name for the new role.

  7. Type the name of a resource to see the list of permissions.

  8. Add one or more permissions by using one of the following methods:

    • From the Permissions list, select a permission and click the Add selected icon.

    • Click the Add all icon to select all the permissions for that resource.

  9. Click Create.
